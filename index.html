Summary

I hold a PhD in applied mathematics. My thesis focused on active sampling and surrogate modeling for expensive simulators, in collaboration with NXP Semiconductors and ANITI. My work sits between probability, statistics and machine learning, with a taste for turning methods into code that actually runs. That is how AIMS came about, an open-source Python library for adaptive and iterative model sampling (see the project section).

I now teach mathematics and I am preparing the agrégation, the French competitive teaching examination. Alongside, I build personal software projects to keep learning.

Looking for private maths lessons? See the tutoring page (in French).
